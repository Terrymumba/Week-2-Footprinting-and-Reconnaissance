# Week-2-Footprinting-and-Reconnaissance
Practical cybersecurity lab covering footprinting and reconnaissance using six Kali Linux tools: WHOIS, WhatWeb, Nslookup, cURL, WAFW00F, and DNSRecon.
1. Project Overview
This project is part of my Week 2 practical assessment under the Cybersecurity Internship Program at NetworkWalks Academy.
The objective of this lab was to gain hands-on experience in footprinting and reconnaissance using various built-in Kali Linux tools.
During this assessment, I conducted an authorised reconnaissance exercise on the training target:
Target Website: networkwalks.com
The exercise focused on gathering publicly accessible information, analysing website technologies, performing DNS lookups, and understanding how different reconnaissance tools contribute to information gathering during a cybersecurity assessment.
________________________________________
2. Objectives
The main objectives of this practical assessment were:
•	Understand the concept of footprinting and reconnaissance.
•	Gain practical experience using Kali Linux reconnaissance tools.
•	Gather publicly available information about a target domain.
•	Understand DNS queries and domain name resolution.
•	Identify website technologies and server information.
•	Learn how to troubleshoot common Kali Linux tool issues.
________________________________________
3. Tools Used
The following six Kali Linux tools were used during this assessment:
No.	Tool	Purpose
1	WHOIS	Retrieves domain registration information.
2	WhatWeb	Identifies website technologies and frameworks.
3	Nslookup	Performs DNS queries and domain resolution.
4	cURL	Retrieves website headers and server responses.
5	WAFW00F	Identifies Web Application Firewall technologies.
6	DNSRecon	Performs DNS information gathering and enumeration.
________________________________________
4. Practical Implementation & Findings
Each tool was used to gather a different category of information about the authorised training target.
4.1 WHOIS
WHOIS was used to retrieve publicly available domain registration information.
Purpose:
•	Examine domain registration details.
•	Identify registrar information.
•	Understand domain registration records.
